# Knowledge formulation

When adding or editing memory notes, follow these rules adapted from [SuperMemo: Effective learning: Twenty rules of formulating knowledge](https://www.supermemo.com/en/blog/twenty-rules-of-formulating-knowledge)

1. Understand the material before memorizing it
2. Learn the surrounding idea before turning details into cards
3. Build from basics before adding complexity
4. Keep each card as small and atomic as possible
5. Use cloze deletion for fast extraction of simple facts
6. Use images when visuals carry the idea better than words
7. Use mnemonic techniques for material that resists simple recall
8. Use image occlusion for visual material like maps, diagrams, and anatomy
9. Avoid unordered sets
10. Avoid long ordered lists
11. Reduce interference between similar cards
12. Tighten wording until prompts are direct and easy to answer
13. Connect new cards to existing memories
14. Personalize cards and add concrete examples
15. Use vivid or emotional cues when they clarify the memory
16. Add context labels when they make prompts shorter
17. Use redundant cards when different angles improve recall
18. Include sources for non-obvious claims
19. Add dates or version labels to facts that can become outdated
20. Prioritize what deserves review time
