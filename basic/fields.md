# Basic - Field Structure

This note type uses the built in Anki Basic field structure.

## Fields

1. **Front** - The prompt shown before revealing the answer
2. **Back** - The answer shown after revealing the card

## Format

Each note follows the pipe-delimited format:
```
Front|Back
```

## Notes

- Keep fields in this exact order: `Front|Back`
- Use one note per prompt and answer pair
- This note type can be reused across many decks
